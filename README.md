# Babetta KGP: náhľad webu (Esticode)

Ukážka úvodnej stránky pre Babetta KGP. Nie je to oficiálny web podniku.
Statické HTML bez buildu, nasadenie cez GitHub Pages na `babetta.esticode.sk`.

- `index.html`: celá stránka (inline CSS, bez knižníc)
- `robots.txt`: `Disallow: /` (plus `meta robots noindex, nofollow` v HTML)
- `CNAME`: vlastná subdoména pre GitHub Pages

Neoverené položky sú v `index.html` označené komentárom `TODO-OVERIT`.
